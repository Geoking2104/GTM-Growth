Critical findings

1. The entity layer is the weakest category: 3/10

An AI engine has to decide that “OpenDPE”, the title, the H1 and the Organization record are the same thing. Today they are not aligned.

name: “DPE d'un bien a vendre…” (title/H1) vs Organization schema · sameAs: 0/4 · about link: none

Fix: one brand name across title, og:title, H1 and schema; add sameAs to LinkedIn/Wikidata; link a real about page; reuse the meta description as the Organization description.

2. No AI discovery endpoints: 0/6

None of the four discovery files exist, so an agent has no machine-readable summary, FAQ or capability statement to route on.

GET /.well-known/ai.txt → 404 · /ai/summary.json → 404 · /ai/faq.json → 404 · /ai/service.json → 404

Fix: publish the four files (the generator emits valid shapes); they are static JSON and take minutes.

3. llms.txt is valid but thin: 12/18

Twenty links all resolve, so drift is clean — but the file carries fewer than 1,000 words and has no expanded companion.

20 links · 100% resolve · 11 sitemap pages never linked · no /llms-full.txt

Fix: generate with the sitemap, then add product, documentation and company sections; ship /llms-full.txt for depth.

4. Crawler access is one wildcard edit away

All 27 bots are allowed — via *. A single change to that block would silently remove every AI crawler, and the citation bots have no rule of their own.

robots.txt: 1 group (`*`), 0 explicit citation-bot rules · crawl-delay: none

Fix: add explicit Allow groups for OAI-SearchBot, Claude-SearchBot, PerplexityBot, Googlebot and Applebot.

5. Citability 53/100: the copy is not quotable yet

No quotations, no lists or tables in the inspected page, no question-shaped headings, no outbound citations, no author and no freshness date.

methods passed: 5/12 · weakest: quotations, structure, question headings, citations, authorship, freshness

Fix: add a sourced pull-quote, convert one comparison into a table, phrase two H2s as questions, cite three sources, add an author and dateModified.
