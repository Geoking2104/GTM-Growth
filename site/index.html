    FAQ

    The questions that decide the engagement

    Is the free read a real audit?

    Two layers. The URL score runs in your browser: HTTPS, hostname shape, path depth, tracking parameters, fragments, length, file extensions — that part never fetches anything. The SEO, GA4 and Search Console tables are measured server-side by /api/free-read, on the page, its robots.txt and its sitemap. When that API is not connected, the tables are labelled sample; npm run cli -- geo-free-read --url … gives the same rows locally.

    What is GEO, and how is it different from SEO?

    SEO optimises for a ranked list of links. GEO optimises for being quoted inside an answer: an engine has to fetch the page, parse it, resolve the entity and find a passage worth citing. They overlap — crawler access, structure, metadata — but a page can rank well and still be uncitable, which is why citability is scored separately here.

    How long before AI engines cite me?

    Nobody can promise a date, and any tool that does is guessing. What can be measured: whether crawlers are allowed, whether the entity resolves, whether a passage is quotable, and how fast a change is announced (IndexNow). The report gives you those, plus the projected score once the fixes ship.

    Does this guarantee AI engines will cite me?

    No, and any tool claiming that is guessing. The audit measures readiness: crawler access, llms.txt, structured data, citability, entity signals and discovery endpoints. It never queries ChatGPT, Claude or Perplexity, so it cannot claim an engine cites you.

    Do you need access to my Google account?

    Only for the GA4 and Tag Manager audits. Those use a service account invited to your properties with viewer access. Every write — tags, sitemaps, Indexing API, Measurement Protocol secrets — is disabled by default and requires a flag plus confirm=true.

    What happens after I submit the form?

    You get the full audit for the URL you entered, the three fixes with the highest recoverable points, and a short list of tracking gaps that would make the numbers unreliable. If it is not a fit, you still keep the audit.

    Is it really open source?

    Yes — Apache-2.0. The GEO rubric is adapted from the MIT-licensed geo-optimizer-skill model, credited in the docs. The server, CLI, site and tests are in the same repository.
